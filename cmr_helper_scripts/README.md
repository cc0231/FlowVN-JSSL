# Challenge evaluation code (third party)

`evaluation2026/` is the CMRx4DFlow 2026 challenge evaluation code (metrics, MSAC
background-phase correction, data I/O), included unmodified so that training-time
validation and `board_eval.py` compute exactly the leaderboard metrics.
